The code is parallelized using MPI for distributed parallelization and OpenMP for shared memory parallelization.

The distribution of the image among the nodes was done using static blocking method, where the rows of pixels in the image are statically divided among all nodes.
OpenMP is used to further divide the given rows among the processors available per node.
After the final computations are done and the local copies of the red, green and blue arrays are updated for each process, MPI_send is called for every process other than root,
and MPI_Recv is called in the root process to recieve the image. This could also be done by using MPI_Gatherv, but as tested, there was not much of a difference in speedup. 
Finally only the root process writes the red, green and blue arrays to the imagefile, and the time taken for all this is printed by the root process.
